# ADR 0008: Визуализация и Аудио (PixiJS & Web Audio API)

## Контекст (Context)

Необходимо выбрать технологию для отрисовки боя на Canvas и интеграции звуковых эффектов (крики покемонов из PokeAPI). Существует выбор между нативным HTML5 Canvas API (низкоуровнево, сложно анимировать) и сторонними WebGL-движками (например, PixiJS).

## Решение (Decision)

1.  **WebGL Engine (PixiJS):** Для рендеринга используется библиотека PixiJS. Это дает доступ к аппаратному ускорению (WebGL), встроенному графу сцены (Scene Graph) и упрощает создание качественных современных анимаций (спрайты, партиклы, фильтры).
2.  **Аудио Менеджер:** Звуки покемонов (cries) из PokeAPI кэшируются и проигрываются через отдельный `AudioManager` (основанный на Web Audio API или стандартном `HTMLAudioElement`). `CanvasRenderer` во время разбора очереди событий дергает `AudioManager` в нужный момент (например, при выходе покемона на поле или при атаке).

## Последствия (Consequences)

- **Плюс:** Высокая производительность отрисовки (WebGL) и удобный API для разработки анимаций (Tweening, контейнеры).
- **Минус:** Увеличение размера бандла Angular-приложения на размер библиотеки PixiJS.
