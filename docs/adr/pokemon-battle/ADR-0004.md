# ADR 0004: Изоляция ИИ Бота в отдельный сервис

## Контекст (Context)

В локальном режиме игрок сражается против компьютерного противника (Бота). Возникает вопрос, где должна находиться логика принятия решений Бота, чтобы не загрязнять чистый изоморфный `Battle Engine` и подготовить почву для мультиплеера.

## Решение (Decision)

1.  **Внешний Актер:** Логика Бота выносится в отдельный изолированный сервис (например, `BotPlayerService`), который существует на стороне клиента (в Angular).
2.  **Слабое Связывание:** `Battle Engine` ничего не знает о существовании "Бота". Для Движка Бот — это просто абстрактный Игрок 2, от которого ожидаются команды (`Command`).
3.  **Асинхронность:** Бот-сервис подписывается на события изменения фазы боя (когда Движок переходит в состояние "Ожидание ввода игрока 2") и асинхронно (возможно, с искусственной задержкой для реализма) отправляет свою команду в Движок.

## Последствия (Consequences)

- **Плюс:** Идеальная чистота `Battle Engine`.
- **Плюс:** В будущем переход на PartyKit будет бесшовным. Мы просто отключим `BotPlayerService` на клиенте и начнем слушать команды от реального Игрока 2 по WebSocket.
