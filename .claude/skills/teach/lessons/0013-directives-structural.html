Directives — структурные

ngIf/ngFor vs @if/@for, ng-container, кастомная структурная директива.

1. Атрибутные vs структурные директивы

Атрибутные Структурные
Меняют вид/поведение элемента Добавляют/удаляют элементы из DOM
[ngClass], [ngStyle] *ngIf, *ngFor, *ngSwitch
Элемент остаётся в DOM Элемент удаляется из DOM при false/пустом массиве

2. ngIf / ngFor / ngSwitch vs control flow

Старый (директивы) Новый (Angular 17+ built-in)
*ngIf="cond; else tpl" @if (cond) { } @else { }
*ngFor="let i of items; trackBy: fn" @for (i of items; track i.id) { }
[ngSwitch] / *ngSwitchCase @switch (x) { @case (v) { } }

Новый control flow компилируется в оптимизированный код без накладных расходов директив. Оба способа работают — но новый предпочтителен в Angular 17+.

3. ng-container

ng-container — невидимый DOM-узел: позволяет применить директиву без добавления лишнего элемента в DOM. 

<!-- Без ng-container пришлось бы обернуть в div -->
<ng-container *ngIf="isLoggedIn">
  <h2>Привет, {{ user.name }}</h2>
  <app-dashboard />
</ng-container>

<!-- С Angular 17+ -->
@if (isLoggedIn) {
  <h2>Привет, {{ user.name }}</h2>
  <app-dashboard />
}

4. ngSwitch / ngSwitchCase / ngSwitchDefault

<div [ngSwitch]="role">
  <span *ngSwitchCase="'admin'">Администратор</span>
  <span *ngSwitchCase="'user'">Пользователь</span>
  <span *ngSwitchDefault>Гость</span>
</div>

5. Кастомная структурная директива

@Directive({
  selector: '[leftPawIfRole]',
  standalone: true,
})
export class IfRoleDirective {
  private vcr = inject(ViewContainerRef);
  private tmpl = inject(TemplateRef);
  private auth = inject(AuthService);

  leftPawIfRole = input<string>('');

  constructor() {
    effect(() => {
      this.vcr.clear();
      if (this.auth.role() === this.leftPawIfRole()) {
        this.vcr.createEmbeddedView(this.tmpl);
      }
    });
  }
}

// использование:
<button *leftPawIfRole="'admin'">Удалить</button>
Механика структурных директив

*directive — это сахар над [directive] + ng-template. Angular раскрывает *leftPawIfRole="'admin'" в: <ng-template [leftPawIfRole]="'admin'"><button>...</button></ng-template>. Директива управляет этим шаблоном через ViewContainerRef.
