Урок 3 из серии «Angular Interview Prep»

Компоненты: базовые

Standalone, @Component, data binding, control flow.

1. Standalone-компоненты vs модульные

Standalone-компоненты (Angular 14+, по умолчанию с Angular 17) — самодостаточные единицы: импортируют зависимости напрямую в декораторе, не нуждаются в NgModule.

Standalone NgModule-based
standalone: true (дефолт) Объявляется в declarations модуля
Импорты прямо в @Component Импорты в @NgModule
Проще, меньше бойлерплейта Больше структуры, сложнее переиспользовать

2. Декоратор @Component

@Component({
  selector: 'left-paw-card',       // CSS-селектор для использования в шаблонах
  templateUrl: './card.component.html', // или template: `...` инлайн
  styleUrl: './card.component.scss',    // или styles: [`...`]
  changeDetection: ChangeDetectionStrategy.OnPush,
  imports: [CommonModule, RouterLink],  // для standalone
})
export class CardComponent { }
Формула ответа

Три обязательных поля: selector (имя тега), template/templateUrl (HTML), styleUrl/styles (стили). В проекте всегда добавляем changeDetection: OnPush.

3. Data Binding

Тип Синтаксис Направление
Interpolation {{ value }} TS → DOM (текст)
Property binding [property]="expr" TS → DOM (свойство)
Event binding (event)="handler()" DOM → TS
Two-way binding [(ngModel)]="val" Оба направления 
<h1>{{ title }}</h1>                     <!-- interpolation -->
<img [src]="imageUrl" />                 <!-- property binding -->
<button (click)="save()">Save</button>  <!-- event binding -->
<input [(ngModel)]="name" />             <!-- two-way -->

4. Односторонняя vs двусторонняя привязка

Односторонняя — данные текут в одном направлении: либо TS→DOM ([prop], {{ }}), либо DOM→TS ((event)).

Двусторонняя — [(ngModel)] — синтаксический сахар над [ngModel] + (ngModelChange). Требует FormsModule. В Reactive Forms двусторонней привязки нет — значение читается через control.value.

Ловушка на интервью

[(x)] — «банан в коробке» — это shorthand для [x]="v" (xChange)="v=$event". Angular разворачивает его в пару property + event binding. Скажи это на интервью — впечатлит.

5. Angular Control Flow: @if, @for, @switch

С Angular 17 встроенные структурные директивы заменены на блоки control flow прямо в шаблоне. Они быстрее (нет нужды в NgIf/NgFor) и дают лучший тайп-чекинг. 

@if (user) {
  <p>{{ user.name }}</p>
} @else {
  <p>Загрузка...</p>
}

@for (item of items; track item.id) {
  <app-card [data]="item" />
} @empty {
  <p>Список пуст</p>
}

@switch (status) {
  @case ('active')  { <span>Активен</span> }
  @case ('banned')  { <span>Заблокирован</span> }
  @default          { <span>Неизвестно</span> }
}
Ловушка на интервью

@for требует обязательного track. Без него — ошибка компиляции. track item.id аналогично trackBy в старом *ngFor — оптимизирует DOM-обновления.
