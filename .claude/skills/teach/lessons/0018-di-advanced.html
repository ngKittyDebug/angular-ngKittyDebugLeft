Dependency Injection — продвинутый

useClass/useValue/useFactory, InjectionToken, @Optional/@Self/@SkipSelf, multi, forwardRef.

1. useClass, useValue, useFactory

// useClass — подменить реализацию
providers: [
  { provide: LogService, useClass: ConsoleLogService },
  // или для тестов:
  { provide: LogService, useClass: MockLogService },
]

// useValue — конфигурация или константы
providers: [
  { provide: API_URL, useValue: 'https://api.example.com' },
]

// useFactory — динамическое создание (может инжектить зависимости)
providers: [
  {
    provide: FeatureFlags,
    useFactory: (http: HttpClient) => new FeatureFlags(http, environment.flagsUrl),
    deps: [HttpClient],
  },
]

2. InjectionToken

// Токен для non-class значений:
export const API_URL = new InjectionToken<string>('API_URL');

// Регистрация:
providers: [{ provide: API_URL, useValue: 'https://api.example.com' }]

// Инжекция:
export class ApiService {
  private url = inject(API_URL);
}
Зачем InjectionToken?

Классы сами служат токенами DI. Но для строк, чисел, объектов нужен токен. InjectionToken<T> типизирован — TypeScript знает тип значения при inject().

3. @Optional, @Self, @SkipSelf

export class MyComponent {
  // @Optional — не выбросит ошибку если зависимость не найдена
  private logger = inject(LogService, { optional: true });

  // @Self — ищет только в injector текущего компонента
  private service = inject(MyService, { self: true });

  // @SkipSelf — пропускает injector текущего компонента
  private parent = inject(MyService, { skipSelf: true });
}

В современном Angular inject(Token, { optional: true, self: true, skipSelf: true, host: true }) заменяет декораторы @Optional(), @Self(), @SkipSelf(), @Host().

4. multi-provider

// Несколько провайдеров для одного токена
export const HTTP_INTERCEPTORS = new InjectionToken<HttpInterceptorFn[]>('...');

providers: [
  { provide: HTTP_INTERCEPTORS, useValue: authInterceptor, multi: true },
  { provide: HTTP_INTERCEPTORS, useValue: loggingInterceptor, multi: true },
]

// inject вернёт массив:
const interceptors = inject(HTTP_INTERCEPTORS); // [authFn, loggingFn]

Angular использует multi для HTTP_INTERCEPTORS, APP_INITIALIZER, LOCALE_ID и других системных токенов.

5. forwardRef

// Проблема: A зависит от B, B объявлен ниже A в файле
@Component({
  providers: [
    {
      provide: NG_VALUE_ACCESSOR,
      useExisting: forwardRef(() => MyInputComponent), // компонент ещё не объявлен
      multi: true,
    },
  ],
})
export class MyInputComponent { }
Ловушка на интервью

forwardRef нужен когда ссылаешься на класс, который ещё не объявлен в JavaScript — обычно при circular dependency или когда компонент ссылается на себя в декораторе (например, регистрируя себя как ControlValueAccessor через useExisting).

6. Иерархия инжекторов

// Поиск зависимости идёт снизу вверх:
// Element Injector (компонент) → Parent Element Injectors → Module Injector → Root Injector → Platform Injector → NULL

// Пример: компонент имеет свой экземпляр MyService:
@Component({
  providers: [MyService], // свой injector
})
export class ChildComponent {
  private s = inject(MyService); // найдёт в своём, не в root
}
