Forms — ControlValueAccessor

CVA — мост между кастомным компонентом и Angular Forms API.

1. Что такое ControlValueAccessor?

ControlValueAccessor (CVA) — интерфейс, позволяющий кастомному компоненту работать как элемент формы: использоваться с formControlName, [(ngModel)] и стандартными валидаторами.

Когда нужен CVA

Когда создаёшь кастомный UI-элемент ввода (date picker, phone mask, star rating, tag input) и хочешь, чтобы он нативно интегрировался с Angular Forms — работал как <input>.

2. Интерфейс CVA

interface ControlValueAccessor {
  writeValue(value: T): void;       // Forms → компонент: установить значение
  registerOnChange(fn: Function): void;   // сохранить коллбек для уведомления Forms
  registerOnTouched(fn: Function): void;  // сохранить коллбек "поле тронуто"
  setDisabledState?(disabled: boolean): void; // опционально
}

3. Реализация кастомного контрола

@Component({
  selector: 'left-paw-rating',
  standalone: true,
  template: `
    @for (star of stars; track star) {
      <button (click)="select(star)"
              [class.active]="star <= (value ?? 0)">★</button>
    }
  `,
  providers: [
    {
      provide: NG_VALUE_ACCESSOR,
      useExisting: forwardRef(() => RatingComponent),
      multi: true,
    },
  ],
})
export class RatingComponent implements ControlValueAccessor {
  protected stars = [1, 2, 3, 4, 5];
  protected value: number | null = null;
  protected isDisabled = false;

  private onChange = (_: number | null) => {};
  private onTouched = () => {};

  // Forms пишет в компонент
  writeValue(v: number | null) { this.value = v; }

  // Компонент уведомляет Forms
  registerOnChange(fn: (v: number | null) => void) { this.onChange = fn; }
  registerOnTouched(fn: () => void) { this.onTouched = fn; }
  setDisabledState(disabled: boolean) { this.isDisabled = disabled; }

  protected select(star: number) {
    if (this.isDisabled) return;
    this.value = star;
    this.onChange(star);
    this.onTouched();
  }
}

// Использование:
// <left-paw-rating formControlName="rating" />

4. Кастомный валидатор для Template-driven Forms

@Directive({
  selector: '[leftPawMinAge]',
  standalone: true,
  providers: [
    { provide: NG_VALIDATORS, useExisting: MinAgeDirective, multi: true },
  ],
})
export class MinAgeDirective implements Validator {
  minAge = input(18);

  validate(control: AbstractControl): ValidationErrors | null {
    const age = Number(control.value);
    return age >= this.minAge()
      ? null
      : { minAge: { required: this.minAge(), actual: age } };
  }
}

// Использование:
// <input ngModel leftPawMinAge [minAge]="21" name="age" />
Ловушка на интервью

Обязательно использовать forwardRef(() => MyComponent) при регистрации через useExisting — иначе JavaScript выбросит ошибку «Class used before declaration». Это одна из немногих ситуаций, где forwardRef реально нужен.
