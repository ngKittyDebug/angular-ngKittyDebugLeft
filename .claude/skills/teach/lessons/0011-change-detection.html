Change Detection

Default vs OnPush, markForCheck vs detectChanges, Signals и CD.

1. Что такое Change Detection?

Change Detection (CD) — механизм Angular, который синхронизирует состояние компонентов с DOM. После каждого browser event, HTTP-ответа, таймера Angular обходит дерево компонентов и перерисовывает те, чьё состояние изменилось.

2. Стратегии: Default vs OnPush

Default OnPush
Проверяет при ЛЮБОМ событии Проверяет только при триггерах
Просто, предсказуемо Производительнее для больших деревьев
Подходит для простых приложений Обязателен в серьёзных проектах

3. Когда Angular проверяет OnPush компонент?

OnPush компонент перепроверяется при следующих условиях:

  1. Изменилась ссылка на @Input() (не значение внутри объекта)
  2. Произошло событие внутри компонента или его потомков (click, keyup...)
  3. Сработал async pipe в шаблоне
  4. Вручную вызван markForCheck() или detectChanges()
  5. Изменился Signal, читаемый в шаблоне
Ловушка на интервью

При OnPush: this.items.push(newItem) — мутация массива — не триггерит CD, потому что ссылка на массив не изменилась. Нужно: this.items = [...this.items, newItem].

4. markForCheck() vs detectChanges()

markForCheck() detectChanges()
Помечает компонент и предков Запускает CD немедленно для поддерева
Асинхронно — при следующем CD-цикле Синхронно — прямо сейчас
Предпочтительно для большинства случаев Для критичных к времени UI-обновлений 
export class MyComponent {
  private cdr = inject(ChangeDetectorRef);

  // В callback из сторонней библиотеки (вне Zone.js):
  onExternalUpdate() {
    this.data = newData;
    this.cdr.markForCheck(); // предпочтительно
    // или
    this.cdr.detectChanges(); // если нужно немедленно
  }
}

5. Signals и Change Detection

С Signals не нужны ни markForCheck(), ни detectChanges(). Angular отслеживает, какие сигналы читаются в шаблоне, и при изменении сигнала автоматически планирует обновление нужных компонентов — даже с OnPush. 

@Component({
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `<p>{{ count() }}</p>`,
})
export class Counter {
  count = signal(0);

  // Сигнал изменился → Angular сам перерисует → markForCheck не нужен
  increment() { this.count.update(n => n + 1); }
}
