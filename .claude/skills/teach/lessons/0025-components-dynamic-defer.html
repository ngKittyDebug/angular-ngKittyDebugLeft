Dynamic Components + @defer

ViewContainerRef, ngComponentOutlet, deferrable views.

1. Динамические компоненты через ViewContainerRef

@Component({
  template: `<div #container></div>`,
})
export class ModalHostComponent {
  private vcr = viewChild.required<ViewContainerRef>('container', {
    read: ViewContainerRef,
  });

  open<T>(component: Type<T>, inputs?: Partial<T>) {
    const vcr = this.vcr();
    vcr.clear();

    const ref = vcr.createComponent(component);

    // Передача inputs:
    if (inputs) {
      Object.assign(ref.instance as object, inputs);
      ref.changeDetectorRef.detectChanges();
    }

    return ref;
  }
}
Когда использовать

Динамическое создание через ViewContainerRef нужно когда тип компонента неизвестен на этапе компиляции — например, в система плагинов, модальных окнах, toast-нотификациях, динамических формах.

2. ngComponentOutlet — декларативный динамический рендер

// В компоненте:
export class TabsComponent {
  protected activeTab = signal<Type<unknown>>(HomeTabComponent);

  switch(tab: Type<unknown>) { this.activeTab.set(tab); }
}

// В шаблоне:
<ng-container [ngComponentOutlet]="activeTab()" />

// С inputs и injector:
<ng-container
  [ngComponentOutlet]="activeTab()"
  [ngComponentOutletInputs]="{ userId: currentUserId() }"
/>
ViewContainerRef ngComponentOutlet
Императивный — в TypeScript Декларативный — в шаблоне
Полный контроль lifecycle Автоматическое управление
Для сложных сценариев Для простого switch компонентов

3. @defer — отложенный рендер

@defer (on viewport) {
  <left-paw-heavy-chart [data]="chartData()" />
} @placeholder {
  <div class="skeleton">Загрузка графика...</div>
} @loading (minimum 300ms) {
  <left-paw-spinner />
} @error {
  <p>Не удалось загрузить компонент</p>
}

4. Условия @defer

Условие Когда загружается
on viewport Когда placeholder попадает в область видимости
on idle Когда браузер простаивает (requestIdleCallback)
on interaction При клике/наведении на placeholder
on hover При наведении мыши
when condition() Когда сигнал/выражение станет truthy
on timer(2s) Через N миллисекунд/секунд

5. Как @defer помогает производительности

Компоненты в @defer блоке не включаются в initial bundle — они загружаются отдельным чанком только при выполнении условия. Angular автоматически делает dynamic import() для этих компонентов.

Сравни с @if: @if скрывает компонент, но код всё равно в бандле. @defer — код загружается позже.

Ловушка на интервью

@placeholder всегда рендерится немедленно (синхронно) и виден до загрузки компонента. @loading — только пока идёт загрузка бандла. Оба опциональны, но @placeholder улучшает UX — пользователь видит «место» компонента.
