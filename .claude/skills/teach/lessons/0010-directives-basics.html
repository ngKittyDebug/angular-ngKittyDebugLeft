Directives — базовые

Типы директив, @Directive, HostBinding, HostListener, ElementRef vs Renderer2.

1. Что такое Directives?

Директивы — классы, расширяющие поведение HTML-элементов без создания отдельного компонента. Компонент — это директива с шаблоном.

2. Три типа директив

Тип Пример Что делает
Компонентная <app-card /> Директива + шаблон + стили
Атрибутная [leftPawHideContent] Меняет вид/поведение элемента
Структурная *ngIf, *ngFor Добавляет/удаляет DOM-элементы

3. Создание атрибутной директивы

@Directive({
  selector: '[leftPawHighlight]',
  standalone: true,
})
export class HighlightDirective {
  private el = inject(ElementRef);
  color = input('yellow');

  @HostListener('mouseenter')
  onEnter() {
    this.el.nativeElement.style.backgroundColor = this.color();
  }

  @HostListener('mouseleave')
  onLeave() {
    this.el.nativeElement.style.backgroundColor = '';
  }
}

// использование:
<p leftPawHighlight [color]="'pink'">Наведи мышь</p>

4. HostBinding и HostListener

@Directive({ selector: '[leftPawActive]' })
export class ActiveDirective {
  private isActive = signal(false);

  // Привязывает CSS-класс к хост-элементу
  @HostBinding('class.active')
  get active() { return this.isActive(); }

  // Слушает событие на хост-элементе
  @HostListener('click')
  onClick() { this.isActive.update(v => !v); }
}

Современная альтернатива — свойство host в декораторе (предпочтительно): 

@Directive({
  selector: '[leftPawActive]',
  host: {
    '[class.active]': 'isActive()',
    '(click)': 'onClick()',
  },
})
export class ActiveDirective {
  protected isActive = signal(false);
  protected onClick() { this.isActive.update(v => !v); }
}
Формула ответа

host: { ... } в декораторе = декларативно, всё видно сразу. @HostBinding/@HostListener — декораторы на методах/свойствах. Оба подхода эквивалентны, но host предпочтительнее в современном Angular.

5. ElementRef vs Renderer2

ElementRef Renderer2
Прямой доступ к DOM-элементу Абстракция над DOM-манипуляциями
Небезопасно (XSS, SSR) Безопасно для SSR и Web Workers
el.nativeElement.style.color = 'red' renderer.setStyle(el.nativeElement, 'color', 'red')
Ловушка на интервью

ElementRef.nativeElement напрямую — антипаттерн при SSR (там нет DOM) и потенциальная дыра XSS. Предпочитай Renderer2 для DOM-манипуляций в директивах.
