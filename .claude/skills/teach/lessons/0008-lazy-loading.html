Урок 8 из серии «Angular Interview Prep»

Lazy Loading

loadComponent, loadChildren, preload strategies, отладка.

1. Что такое Lazy Loading?

Lazy Loading — загрузка JS-бандла только тогда, когда пользователь переходит на маршрут. Без него весь код загружается при первом открытии приложения.

Цель: уменьшить initial bundle, ускорить первую загрузку (Time to Interactive).

2. Преимущества

Без lazy loading С lazy loading
Один большой main.js Маленький main.js + отдельные чанки
Медленная первая загрузка Быстрый старт, чанки грузятся по требованию
Весь код у всех пользователей Код грузится только тем, кто заходит на маршрут

3. loadComponent vs loadChildren

// loadComponent — для отдельного standalone компонента
{
  path: 'about',
  loadComponent: () =>
    import('./features/about/about.component')
      .then(m => m.AboutComponent),
}

// loadChildren — для массива маршрутов (feature routes)
{
  path: 'games',
  loadChildren: () =>
    import('./features/games/games.routes')
      .then(m => m.GAMES_ROUTES),
}

// games.routes.ts
export const GAMES_ROUTES: Routes = [
  { path: '', component: GamesHubComponent },
  { path: 'frenzy', loadComponent: () => import('./frenzy') },
];
Формула ответа

loadComponent — для одного компонента. loadChildren — для группы маршрутов (feature module без NgModule). В современном Angular (standalone) loadChildren возвращает массив Routes, не NgModule.

4. Preload Strategies

Preloading — загрузка lazy-чанков в фоне после первоначальной загрузки приложения. 

// NoPreloading (дефолт) — грузит только при навигации
provideRouter(routes, withNoPreloading())

// PreloadAllModules — грузит ВСЕ lazy-маршруты в фоне
provideRouter(routes, withPreloading(PreloadAllModules))

// Custom strategy
export class SelectivePreloadStrategy implements PreloadingStrategy {
  preload(route: Route, load: () => Observable<unknown>) {
    return route.data?.['preload'] ? load() : EMPTY;
  }
}
// { path: 'about', loadComponent: ..., data: { preload: true } }

5. Отладка проблем с lazy loading

Chrome DevTools → Network вкладка: фильтр по JS — видны chunk-файлы при навигации.

Ошибка «Cannot load chunk»: обычно — неверный путь в import() или опечатка в имени экспорта.

Ошибка «No component factory found»: компонент не standalone и не объявлен в NgModule.

Bundle analyzer: ng build --stats-json + webpack-bundle-analyzer для визуализации размера чанков.

Ловушка на интервью

Если сервис помечен providedIn: 'root', он НЕ войдёт в lazy-чанк — он будет в main bundle. Для сервиса, который нужен только одному lazy-маршруту, используй providers в объекте маршрута.
