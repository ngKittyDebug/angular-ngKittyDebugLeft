Forms

Template-driven vs Reactive, FormBuilder, валидаторы, async validation.

1. Template-driven vs Reactive Forms

Template-driven Reactive Forms
Логика в шаблоне (ngModel) Логика в TypeScript (FormControl)
Асинхронная инициализация Синхронная, предсказуемая
Проще для маленьких форм Лучше масштабируется, тестируется
Требует FormsModule Требует ReactiveFormsModule

2. FormControl, FormGroup, FormArray

// FormControl — один контрол
const name = new FormControl('', [Validators.required, Validators.minLength(2)]);

// FormGroup — группа контролов
const form = new FormGroup({
  name: new FormControl('', Validators.required),
  email: new FormControl('', [Validators.required, Validators.email]),
});

// FormArray — динамический список контролов
const phones = new FormArray([
  new FormControl(''),
  new FormControl(''),
]);

3. FormBuilder — краткий синтаксис

export class LoginComponent {
  private fb = inject(FormBuilder);

  form = this.fb.group({
    email: ['', [Validators.required, Validators.email]],
    password: ['', [Validators.required, Validators.minLength(8)]],
  });

  submit() {
    if (this.form.valid) {
      console.log(this.form.value); // { email: '...', password: '...' }
    }
  }
}

4. Валидация в Template-driven vs Reactive

Template-driven Reactive
required minlength атрибуты в HTML Validators.required в TS
Кастомный: директива с Validator Кастомный: функция ValidatorFn 
// Кастомный валидатор (Reactive)
function noSpaces(): ValidatorFn {
  return (control) =>
    control.value?.includes(' ')
      ? { noSpaces: true }
      : null;
}

// Использование:
email: ['', [Validators.required, noSpaces()]]

// В шаблоне:
@if (form.get('email')?.errors?.['noSpaces']) {
  <span>Пробелы не допускаются</span>
}

5. Отслеживание состояния формы

// valueChanges — реагируем на изменения значений
this.form.get('email')!.valueChanges
  .pipe(debounceTime(300), distinctUntilChanged())
  .subscribe(value => this.checkEmail(value));

// statusChanges — VALID | INVALID | PENDING | DISABLED
this.form.statusChanges.subscribe(status => {
  this.isLoading = status === 'PENDING';
});

6. Async валидация

function emailUniqueValidator(userService: UserService): AsyncValidatorFn {
  return (control) =>
    userService.checkEmail(control.value).pipe(
      map(isUnique => isUnique ? null : { emailTaken: true }),
      catchError(() => of(null)),
    );
}

// Регистрация:
email: ['', [Validators.email], [emailUniqueValidator(userService)]]
// 3-й аргумент — async validators
Ловушка на интервью

Пока async валидатор ждёт ответа, control.status === 'PENDING'. Всегда добавляй debounceTime чтобы не слать запрос при каждом нажатии клавиши.
