Signals — базовый

signal(), computed(), effect() — реактивные примитивы Angular.

1. Что такое Signals?

Signal — обёртка над значением, которая отслеживает, кто её читает, и уведомляет зависимости при изменении. Введены в Angular 16, стабильны с Angular 17.

Формула ответа

Сигнал — это реактивный контейнер: при изменении значения Angular автоматически знает, какие шаблоны и computed нужно обновить, без ручного detectChanges() или markForCheck().

2. Как читать и изменять значение

import { signal, computed, effect } from '@angular/core';

// Создание
const count = signal(0);          // WritableSignal<number>
const name  = signal<string>(''); // явный тип

// Чтение — вызов как функции
console.log(count()); // 0

// Изменение
count.set(5);          // прямая замена
count.update(n => n + 1); // через предыдущее значение
count.mutate(arr => arr.push(item)); // для объектов/массивов (mutate)

// Производное значение
const doubled = computed(() => count() * 2); // ReadonlySignal
console.log(doubled()); // 10 — пересчитывается автоматически
Метод Что делает
signal(v) Создаёт WritableSignal с начальным значением v
sig.set(v) Заменяет значение новым
sig.update(fn) Вычисляет новое значение через предыдущее
computed(() => ...) Производный ReadonlySignal, кешируется до изменения зависимостей
effect(() => ...) Side effect: выполняется при изменении читаемых сигналов

3. Главное преимущество перед примитивными значениями

С обычной переменной Angular не знает, изменилась ли она — нужен Zone.js или ручной триггер. Signal отслеживает зависимости автоматически: шаблон читает count(), Angular запоминает эту связь и перерисовывает только нужные части при count.set().

Signals — основа для Zoneless Angular (без Zone.js): полная реактивность без monkey-patching браузерных API. Это будущее Angular.

4. В шаблоне

@Component({
  template: `
    <p>Счёт: {{ count() }}</p>       <!-- вызов с () -->
    <p>Удвоен: {{ doubled() }}</p>
    <button (click)="increment()">+</button>
  `,
})
export class CounterComponent {
  protected count = signal(0);
  protected doubled = computed(() => this.count() * 2);

  protected increment() {
    this.count.update(n => n + 1);
  }
}
Ловушка на интервью

В шаблоне сигнал читается с (): {{ count() }}, не {{ count }}. Без скобок выведется объект Signal, а не его значение.
