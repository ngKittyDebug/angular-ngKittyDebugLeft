Modules (NgModule)

Структура NgModule, роль в приложении, современный standalone-мир.

1. Что такое NgModule?

NgModule — контейнер, объединяющий компоненты, директивы, пайпы и сервисы в связные функциональные блоки. До Angular 14 — единственный способ организации приложения. В Angular 17+ standalone компоненты — дефолт, NgModule уходит в прошлое, но спрашивают о нём на интервью постоянно.

2. Структура NgModule

@NgModule({
  declarations: [
    AppComponent,
    HeaderComponent,   // компоненты/директивы/пайпы этого модуля
  ],
  imports: [
    BrowserModule,     // другие модули, чьи экспорты нужны здесь
    RouterModule,
    HttpClientModule,
  ],
  exports: [
    HeaderComponent,   // что доступно другим модулям
  ],
  providers: [
    UserService,       // сервисы для DI (лучше использовать providedIn)
  ],
  bootstrap: [AppComponent], // только в корневом AppModule
})
export class AppModule { }
Поле Что в нём
declarations Компоненты, директивы, пайпы этого модуля
imports Модули, экспорты которых нужны в декларациях
exports Что становится доступным при импорте этого модуля
providers Сервисы для injector этого модуля
bootstrap Корневой компонент (только в AppModule)

3. Разделение на Feature Modules

// user.module.ts
@NgModule({
  declarations: [UserListComponent, UserCardComponent],
  imports: [CommonModule, RouterModule],
  exports: [UserCardComponent], // только нужное наружу
})
export class UserModule { }

// app.module.ts
@NgModule({
  imports: [BrowserModule, UserModule, ...],
  bootstrap: [AppComponent],
})
export class AppModule { }

4. Standalone vs NgModule — современный мир

В Angular 17+ standalone компоненты — дефолт. Новые проекты создаются без NgModule.

NgModule подход Standalone подход
Компонент в declarations модуля standalone: true, импорты в @Component
Провайдеры в NgModule.providers Провайдеры в app.config.ts или маршруте
Lazy: loadChildren → NgModule Lazy: loadChildren → Routes[], loadComponent → Component
Ловушка на интервью

Компонент объявлен в NgModule И помечен standalone: true — ошибка компиляции. Standalone компонент нельзя добавлять в declarations. Его можно только importировать в другой standalone компонент или NgModule.

Проверь себя

Retrieval practice — не подглядывай в текст выше. Выбери один вариант.

1. В каком поле NgModule объявляются компоненты этого модуля?

2. Что нужно добавить в exports, чтобы другой модуль мог использовать компонент?

3. Standalone компонент и NgModule: можно ли standalone объявить в declarations?

4. В каком поле NgModule указывается корневой компонент приложения?
