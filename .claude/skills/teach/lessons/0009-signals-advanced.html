Урок 9 из серии «Angular Interview Prep»

Signals — продвинутый

effect(), untracked(), linkedSignal, change detection, отладка.

1. effect() — реакция на изменения

export class ThemeComponent {
  private theme = inject(ThemeService).currentTheme;

  constructor() {
    effect(() => {
      // Читаем theme() — создаём зависимость
      document.body.classList.toggle('dark', this.theme() === 'dark');
    });
  }
}

effect() выполняется при создании и при каждом изменении сигналов, которые читались внутри него. Автоматически очищается при уничтожении компонента.

Ловушка на интервью

effect() должен объявляться в injection context — в конструкторе или через runInInjectionContext(). Нельзя вызывать произвольно в методах класса.

2. untracked() — чтение без зависимости

import { untracked } from '@angular/core';

effect(() => {
  const userId = this.selectedId();       // зависимость: re-run при изменении
  const token = untracked(() => this.authToken()); // без зависимости: не триггерит
  this.load(userId, token);
});

untracked() позволяет прочитать сигнал внутри computed или effect без создания зависимости — effect не будет перезапускаться при изменении этого сигнала.

3. Signals и Change Detection

Компонент с OnPush и сигналами: Angular автоматически помечает компонент для перепроверки, когда сигнал, читаемый в шаблоне, изменяется. Не нужны markForCheck() или detectChanges(). 

@Component({
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `<p>{{ count() }}</p>`, // читаем signal
})
export class MyComponent {
  count = signal(0);
  increment() { this.count.update(n => n + 1); } // Angular сам знает об обновлении
}

Signals — основа для будущего Zoneless Angular: без Zone.js change detection запускается только при изменении сигналов, не при каждом browser event.

4. linkedSignal — реактивная замена defaultValue

import { linkedSignal } from '@angular/core';

export class PaginationComponent {
  pageSize = input(10);

  // При изменении pageSize — сбрасывается до 1
  currentPage = linkedSignal(() => {
    this.pageSize(); // зависимость
    return 1;        // значение при сбросе
  });
}
linkedSignal vs computed

computed — ReadOnly, нельзя изменить извне.
linkedSignal — WritableSignal: можно менять локально (.set()), но при изменении зависимости — сбрасывается по функции. Идеален для «сброс при изменении параметра».

5. Отладка сигналов

Angular DevTools (расширение Chrome): показывает граф зависимостей сигналов и computed-цепочки.

effect() для логирования:

// Временно — для отладки
effect(() => console.log('count changed:', this.count()));

// Проверить, есть ли зависимость в computed:
const debug = computed(() => {
  console.log('recomputing');
  return this.a() + this.b();
});
Ловушка на интервью

Если computed пересчитывается слишком часто — проверь, не читаешь ли ты объект по ссылке. signal({ a: 1 }) при .set({ a: 1 }) создаёт новый объект, что считается изменением. Используй .update() с мутацией или equalsFn в signal(val, { equal: deepEqual }).
