HTTP

HttpClient, interceptors, обработка ошибок, кеширование.

1. HttpClient — подключение и базовое использование

// app.config.ts
providers: [provideHttpClient(withInterceptors([authInterceptor]))]

// В сервисе:
@Injectable({ providedIn: 'root' })
export class PokemonService {
  private http = inject(HttpClient);

  getAll() {
    return this.http.get<Pokemon[]>('/api/pokemon');
  }

  getById(id: number) {
    return this.http.get<Pokemon>(`/api/pokemon/${id}`);
  }

  create(data: CreatePokemonDto) {
    return this.http.post<Pokemon>('/api/pokemon', data);
  }

  update(id: number, data: Partial<Pokemon>) {
    return this.http.put<Pokemon>(`/api/pokemon/${id}`, data);
  }

  delete(id: number) {
    return this.http.delete<void>(`/api/pokemon/${id}`);
  }
}
Ловушка на интервью

HttpClient возвращает cold Observable — запрос не отправляется до подписки. Если не подписаться — сервер никогда не получит запрос.

2. Observable vs Promise для HTTP

Observable (HttpClient) Promise
Можно отменить (unsubscribe) Нельзя отменить
Богатый набор операторов (retry, map) Только .then/.catch
Работает с RxJS пайплайном Проще для одноразовых запросов

3. Обработка ошибок

this.http.get<User>('/api/user')
  .pipe(
    catchError((error: HttpErrorResponse) => {
      if (error.status === 401) {
        this.auth.logout();
      }
      return throwError(() => new Error(error.message));
    }),
    retry(3), // повторить 3 раза при ошибке
  )
  .subscribe({
    next: user => this.user.set(user),
    error: err => this.error.set(err.message),
  });

4. HttpInterceptor — функциональный API

// auth.interceptor.ts
export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const token = inject(AuthService).getToken();

  if (!token) return next(req);

  const authReq = req.clone({
    headers: req.headers.set('Authorization', `Bearer ${token}`),
  });

  return next(authReq);
};

// logging.interceptor.ts
export const loggingInterceptor: HttpInterceptorFn = (req, next) => {
  console.log(`--> ${req.method} ${req.url}`);
  return next(req).pipe(
    tap(event => {
      if (event instanceof HttpResponse) {
        console.log(`<-- ${event.status}`);
      }
    }),
  );
};

Interceptors выполняются в порядке регистрации при запросе, в обратном — при ответе.

5. Кеширование

// 1. shareReplay — кешировать Observable в памяти
export class ConfigService {
  private config$ = this.http.get<Config>('/api/config').pipe(
    shareReplay(1), // кешируем последний ответ, повторные подписчики получают кеш
  );
}

// 2. HttpContext — пометить запрос для interceptor кеша
export const CACHEABLE = new HttpContextToken(() => false);

this.http.get('/api/data', {
  context: new HttpContext().set(CACHEABLE, true),
});
