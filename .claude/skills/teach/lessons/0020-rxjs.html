RxJS

Observable/Subject/BehaviorSubject, операторы, hot vs cold, отписка.

1. Observable, Observer, Subscription

// Observable — поток значений (ленивый)
const count$ = new Observable<number>(observer => {
  observer.next(1);
  observer.next(2);
  observer.complete();
  // или observer.error(err)
});

// Observer — потребитель
const sub = count$.subscribe({
  next: v => console.log(v),    // 1, 2
  error: e => console.error(e),
  complete: () => console.log('done'),
});

// Subscription — управление подпиской
sub.unsubscribe();

2. Observable vs Promise

Observable Promise
Ленивый — запускается при subscribe Eager — запускается немедленно
Может эмитить 0..N значений Одно значение или ошибка
Отменяем (unsubscribe) Не отменяем
Богатые операторы Только .then/.catch/.finally

3. Базовые операторы

source$.pipe(
  map(v => v * 2),                 // трансформация каждого значения
  filter(v => v > 0),              // фильтрация
  tap(v => console.log(v)),        // side effect без трансформации
  take(5),                         // взять первые 5 значений
  debounceTime(300),               // ждать 300мс тишины
  distinctUntilChanged(),          // пропустить если не изменилось
)

// Комбинирование:
combineLatest([a$, b$])   // эмитит при изменении любого, нужны оба
forkJoin([req1$, req2$])  // ждёт завершения всех, эмитит один массив результатов
merge(a$, b$)             // объединяет потоки
zip(a$, b$)               // пары по порядку

4. Subject и BehaviorSubject

// Subject — hot observable, нет начального значения
const events$ = new Subject<string>();
events$.next('click'); // подписчики получат, если уже подписаны

// BehaviorSubject — хранит последнее значение, новые подписчики получают его сразу
const currentUser$ = new BehaviorSubject<User | null>(null);
currentUser$.next(user);
currentUser$.getValue(); // синхронное чтение текущего значения

// В сервисе Angular:
@Injectable({ providedIn: 'root' })
export class AuthService {
  private user$ = new BehaviorSubject<User | null>(null);
  readonly currentUser$ = this.user$.asObservable(); // только чтение

  login(user: User) { this.user$.next(user); }
  logout() { this.user$.next(null); }
}

5. Hot vs Cold Observable

Cold Hot
Поток создаётся для каждого подписчика Поток существует независимо от подписчиков
HttpClient, new Observable() Subject, DOM events, shareReplay()
Поздний подписчик получает ВСЕ значения с начала Поздний подписчик пропускает прошлые события

6. Правильная отписка

// 1. takeUntilDestroyed() — лучший способ (Angular 16+)
export class MyComponent {
  private destroyRef = inject(DestroyRef);

  ngOnInit() {
    this.data$.pipe(takeUntilDestroyed(this.destroyRef)).subscribe(...);
  }
}

// 2. async pipe — авторазотписка в шаблоне
// {{ data$ | async }}

// 3. takeUntil с Subject (старый способ)
private destroy$ = new Subject<void>();
ngOnDestroy() { this.destroy$.next(); this.destroy$.complete(); }
source$.pipe(takeUntil(this.destroy$)).subscribe(...);

7. Retry и обработка ошибок

this.http.get('/api/data').pipe(
  retry(3),                         // повторить 3 раза
  catchError(err => {
    this.toast.error('Ошибка загрузки');
    return of([]);                  // вернуть дефолтное значение
    // или:
    // return throwError(() => err); // пробросить ошибку дальше
  }),
);
