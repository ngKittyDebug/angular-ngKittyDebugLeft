Testing

TestBed, ComponentFixture, моки, fakeAsync, изоляция тестов.

1. Виды тестирования

Вид Что тестирует Инструмент
Unit Один класс/функцию изолированно Vitest, Jest, Karma
Integration Компонент + шаблон + DI TestBed + Vitest
E2E Пользовательский сценарий в браузере Playwright, Cypress

2. TestBed

describe('CardComponent', () => {
  let fixture: ComponentFixture<CardComponent>;
  let component: CardComponent;

  beforeEach(async () => {
    await TestBed.configureTestingModule({
      imports: [CardComponent],               // standalone компонент
      providers: [
        { provide: UserService, useValue: mockUserService },
      ],
    }).compileComponents();

    fixture = TestBed.createComponent(CardComponent);
    component = fixture.componentInstance;
    fixture.detectChanges(); // первый ngOnInit
  });

  it('renders title', () => {
    const h1 = fixture.nativeElement.querySelector('h1');
    expect(h1.textContent).toBe('Заголовок');
  });
});

3. ComponentFixture и DebugElement

// fixture — обёртка над компонентом
fixture.detectChanges();          // запустить CD вручную
fixture.whenStable();             // ждать всех async операций

// nativeElement — прямой DOM
const btn = fixture.nativeElement.querySelector('button');
btn.click();
fixture.detectChanges();

// debugElement — Angular-обёртка
const de = fixture.debugElement;
const titleEl = de.query(By.css('h1'));
const childComp = de.query(By.directive(ChildComponent));

4. Моки зависимостей

// Мок-объект:
const mockUserService = {
  getUser: vi.fn().mockReturnValue(of({ name: 'Oksana' })),
};

// Мок через jasmine.createSpyObj (если Karma):
const mockUserService = jasmine.createSpyObj('UserService', ['getUser']);
mockUserService.getUser.and.returnValue(of({ name: 'Oksana' }));

// В providers:
{ provide: UserService, useValue: mockUserService }

// Проверка вызова:
expect(mockUserService.getUser).toHaveBeenCalledWith('user-id');

5. fakeAsync и tick

it('loads data after 300ms debounce', fakeAsync(() => {
  component.search.setValue('pikachu');

  tick(300); // прокрутить виртуальное время на 300ms

  fixture.detectChanges();

  expect(component.results().length).toBe(1);
}));

// flush() — выполнить все оставшиеся таймеры
// discardPeriodicTasks() — убрать незакрытые interval-ы
fakeAsync vs async/waitForAsync

fakeAsync — синхронный тест с виртуальным временем (tick). Идеален для debounceTime, setTimeout. waitForAsync — реальный async, для HTTP и компиляции шаблонов.

6. Изоляция тестов

afterEach(() => {
  vi.clearAllMocks();     // сбросить вызовы моков
  TestBed.resetTestingModule(); // сбросить DI граф (обычно делает Angular сам)
});
