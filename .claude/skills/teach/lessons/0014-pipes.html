Pipes

Встроенные пайпы, pure vs impure, AsyncPipe, кастомные пайпы.

1. Что такое Pipe?

Pipe — функция-трансформер для шаблонов. Принимает значение, возвращает преобразованное. Синтаксис: {{ value | pipeName : param1 : param2 }}.

2. Встроенные пайпы

{{ date | date:'dd.MM.yyyy' }}         <!-- '25.07.2026' -->
{{ name | uppercase }}                  <!-- 'OKSANA' -->
{{ price | currency:'USD':'symbol' }}   <!-- '$42.00' -->
{{ count | number:'1.0-2' }}            <!-- '1,234.56' -->
{{ obj | json }}                        <!-- JSON.stringify -->
{{ text | slice:0:50 }}                 <!-- первые 50 символов -->
{{ obs$ | async }}                      <!-- подписка + авторазотписка -->

3. Цепочка пайпов

{{ name | uppercase | slice:0:3 }}   <!-- 'OKS' -->
{{ date | date:'longDate' | uppercase }}

4. Параметры пайпа

{{ 3.14159 | number:'1.2-2' }}   <!-- '3.14' — мин 1 цел., 2 дес. -->
{{ today | date:'dd MMM, yyyy' : 'UTC' : 'ru' }}

5. Pure vs Impure пайпы

Pure (default) Impure (pure: false)
Вызывается при изменении ссылки Вызывается при каждом CD-цикле
Быстро — есть кеш Медленно — без кеша
Не видит мутации массива/объекта Видит мутации внутри объектов 
@Pipe({ name: 'filterByStatus', pure: false }) // impure
export class FilterByStatusPipe implements PipeTransform {
  transform(items: Item[], status: string) {
    return items.filter(i => i.status === status);
  }
}
Ловушка на интервью

Impure пайп вызывается на каждом цикле change detection — это дорого. Предпочитай иммутабельные обновления массивов (spread, filter, map) — тогда pure пайп сработает корректно при смене ссылки.

6. AsyncPipe

// В компоненте — НЕ нужно вручную подписываться:
export class UserComponent {
  user$ = inject(UserService).getUser();
}

// В шаблоне:
<div *ngIf="user$ | async as user">
  {{ user.name }}
</div>

// Или с новым control flow:
@if (user$ | async; as user) {
  <p>{{ user.name }}</p>
}

Преимущества AsyncPipe: автоматически подписывается, отписывается при destroy, вызывает markForCheck() при новом значении (работает с OnPush).

7. Кастомный пайп

@Pipe({ name: 'pokemonType', standalone: true })
export class PokemonTypePipe implements PipeTransform {
  transform(type: string, lang: 'ru' | 'en' = 'ru'): string {
    const types: Record<string, Record<string, string>> = {
      fire: { ru: 'Огонь', en: 'Fire' },
      water: { ru: 'Вода', en: 'Water' },
    };
    return types[type]?.[lang] ?? type;
  }
}

// Использование:
{{ pokemon.type | pokemonType:'ru' }}
