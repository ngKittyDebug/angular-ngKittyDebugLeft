Урок 7 из серии «Angular Interview Prep»

Routing

Маршруты, параметры, child routes, guards, ActivatedRoute.

1. Что такое Routing?

Angular Router — встроенный механизм навигации. Сопоставляет URL с компонентами, рендерит их в <router-outlet>, поддерживает историю браузера, lazy loading и guards.

2. Базовая настройка

// app.routes.ts
export const routes: Routes = [
  { path: '', component: HomeComponent },
  { path: 'about', loadComponent: () =>
      import('./features/about/about.component').then(m => m.AboutComponent) },
  { path: '**', component: NotFoundComponent },
];

// app.config.ts
export const appConfig: ApplicationConfig = {
  providers: [provideRouter(routes)],
};

// app.component.html
<router-outlet />

3. Route parameters и queryParams

// routes
{ path: 'pokemon/:id', component: PokemonProfileComponent }

// навигация
router.navigate(['/pokemon', 42]);
router.navigate(['/pokemon', 42], { queryParams: { tab: 'stats' } });
// URL: /pokemon/42?tab=stats

// чтение в компоненте
export class PokemonProfileComponent {
  private route = inject(ActivatedRoute);

  // Signal API (Angular 16+)
  protected id = this.route.snapshot.params['id'];

  // реактивно
  protected id$ = this.route.paramMap.pipe(map(p => p.get('id')));
}

5. Route Guards

// auth.guard.ts
export const authGuard: CanActivateFn = (route, state) => {
  const router = inject(Router);
  const isLoggedIn = !!localStorage.getItem('loginFormData');

  return isLoggedIn
    ? true
    : router.createUrlTree(['/auth/login'], {
        queryParams: { returnUrl: state.url },
      });
};

// routes
{ path: 'profile', component: ProfileComponent, canActivate: [authGuard] }

// CanDeactivate — предотвращает уход со страницы
export const unsavedChangesGuard: CanDeactivateFn<FormComponent> =
  (component) => component.hasUnsavedChanges()
    ? confirm('Есть несохранённые изменения. Уйти?')
    : true;

6. Порядок выполнения guards

При нескольких guards на одном маршруте Angular выполняет их параллельно (если все возвращают Observable/Promise) и ждёт всех. Если хотя бы один вернул false или UrlTree — навигация блокируется.

Ловушка на интервью

Порядок guards в массиве canActivate: [guardA, guardB] не гарантирует последовательного выполнения. Для гарантированной последовательности — один guard, который внутри вызывает логику по очереди.

7. ActivatedRoute

export class DetailComponent {
  private route = inject(ActivatedRoute);

  // Snapshot — текущее состояние, не реактивно
  protected id = this.route.snapshot.paramMap.get('id');
  protected tab = this.route.snapshot.queryParamMap.get('tab');

  // Observable — реактивно при навигации внутри одного компонента
  protected id$ = this.route.paramMap.pipe(map(p => p.get('id')));

  // Данные из resolve
  protected data = this.route.snapshot.data['user'];
}
Snapshot vs Observable

snapshot — используй, если компонент не переиспользуется при навигации между параметрами одного маршрута (напр. /pokemon/1 → /pokemon/2). paramMap$ — для реактивного обновления без пересоздания компонента.
